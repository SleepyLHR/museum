# 宝塔面板部署 Node.js 后端服务

---

## 一、前置准备

### 1.1 确认服务器环境

| 项目 | 要求 |
|------|------|
| 系统 | Linux（宝塔支持 CentOS / Ubuntu / Debian） |
| 宝塔版本 | 最新版 |
| Node.js | 18+（通过宝塔安装） |
| pm2 | 通过 npm 安装 |

### 1.2 开放端口

在宝塔 **安全** → **防火墙** 中开放：
- `3001`（Node.js 服务端口，仅限内网访问）
- `80` / `443`（HTTP/HTTPS，已默认开放）

---

## 二、安装 Node.js（通过宝塔）

### 2.1 宝塔软件商店

```
宝塔面板 → 软件商店 → 搜索 "Node.js版本管理器" → 安装
```

### 2.2 安装 Node.js 18

```
宝塔面板 → 软件商店 → Node.js版本管理器
→ 安装版本：18.x LTS
```

### 2.3 验证安装

```bash
node -v
# 应显示 v18.x.x
```

---

## 三、上传项目文件

### 3.1 创建网站目录

在宝塔 **文件** 中操作：

```
/www/wwwroot/museum-h5/          ← 前端静态文件
/www/wwwroot/museum-server/      ← 后端服务文件
```

### 3.2 上传文件

**方式一：宝塔文件管理器上传**

```
宝塔面板 → 文件 → 进入 museum-server 目录
→ 上传 server/ 目录下的所有文件（除了 node_modules）
```

**方式二：git 拉取（推荐）**

```bash
cd /www/wwwroot/museum-server
git clone 你的仓库地址 .
```

### 3.3 目录结构

```
/www/wwwroot/museum-server/
├── museum-server.js
├── package.json
├── config.example.js
├── config.js              ← 上传后手动创建（不提交到仓库）
└── data/                 ← 自动创建
```

## 四、安装依赖

### 4.1 进入目录

```bash
cd /www/wwwroot/museum-server
```

### 4.2 安装编译工具（如未安装）

```bash
# Ubuntu/Debian
apt update
apt install -y build-essential python3

# CentOS
yum groupinstall -y "Development Tools"
yum install -y python3
```

### 4.3 安装 Node.js 依赖

```bash
npm install
```

正常输出：
```
added 38 packages in 10s
```

## 五、配置文件

### 5.1 创建 config.js

```bash
cd /www/wwwroot/museum-server
cp config.example.js config.js
```

### 5.2 编辑配置

```bash
vim /www/wwwroot/museum-server/config.js
```

参考配置：

```javascript
module.exports = {

  server: {
    port: 3001,
    host: '127.0.0.1',       // 仅监听内网，通过 Nginx 转发
  },

  database: {
    path: './data/data.db',
  },

  wx: {
    enabled: false,           // 开发阶段先设为 false
    appId: '',
    appSecret: '',
    oauthRedirectUri: 'https://你的域名/api/wx/callback',
    redirectAfterOAuth: 'https://你的域名/#/',
    oauthStateSecret: '随机字符串',
  },

  frontend: {
    staticPath: '/www/wwwroot/museum-h5',   // 改为绝对路径
    corsOrigin: 'https://你的域名',          // 改为你的域名
  },

  log: {
    level: 'info',
  },

  security: {
    tokenLength: 32,
    rateLimitPerMinute: 100,
  },
};
```

### 5.3 创建数据目录

```bash
mkdir -p /www/wwwroot/museum-server/data
chmod 755 /www/wwwroot/museum-server/data
```

## 六、设置 Node.js 项目（宝塔方式）

### 6.1 添加 Node.js 项目

```
宝塔面板 → 网站 → Node项目 → 添加Node项目
```

### 6.2 配置项目

| 配置项 | 值 |
|--------|-----|
| 项目名称 | museum-api |
| 项目目录 | `/www/wwwroot/museum-server` |
| 启动文件 | `museum-server.js` |
| 端口 | `3001` |
| 绑定域名 | 不绑定（通过 Nginx 转发） |
| Node版本 | 选择 18.x |

### 6.3 启动项目

点击 **启动**，观察日志确认启动成功。

## 八、配置 Nginx 反向代理

### 8.1 修改网站配置

```
宝塔面板 → 网站 → 点击你的域名 → 设置 → 配置修改
```

### 8.2 添加 API 代理

在 `server {}` 块中添加：

```nginx
    # API 反向代理到 Node.js
    location /api/ {
        proxy_pass http://127.0.0.1:3001;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # 微信 OAuth 回调
    location /wx/ {
        proxy_pass http://127.0.0.1:3001;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
```

### 8.3 重载 Nginx

```
宝塔面板 → 网站 → 点击你的域名 → 设置 → 重载配置
```

## 十一、配置 pm2 开机自启（宝塔 Node 项目默认已配置）

如需手动配置：

```bash
# 安装 pm2
npm install -g pm2

# 启动服务
cd /www/wwwroot/museum-server
pm2 start museum-server.js --name museum-api

# 设置开机自启
pm2 startup
pm2 save
```

## 十三、故障排查

| 问题 | 解决方法 |
|------|----------|
| 页面 502 Bad Gateway | 检查 Node.js 服务是否启动，检查 Nginx 配置 |
| API 返回 500 | 查看 Node.js 日志，检查 config.js 配置 |
| 端口被占用 | `lsof -i :3001`，杀死占用进程 |
| 依赖安装失败 | 确认已安装 build-essential 和 python3 |
| 数据库写入失败 | `chmod 755 /www/wwwroot/museum-server/data` |
